# Main website localisation

The site uses build-time localisation compatible with GitHub Pages.

- English is the complete source language and fallback.
- The planned static locales match the Ride Portal: English, French, Spanish, Russian and Simplified Chinese.
- Public product facts live in `_data/product.yml` and must not be translated by copying them into pages.
- Shared terminology lives in `_data/terminology.yml`.
- Localised pages set `lang` in front matter and use static routes such as `/fr/`.
- A page can define a `translations` map in front matter. The default layout emits `hreflang` links for those routes.
- Missing translations fall back to the English data entry. Do not call a translation service from the browser.

Shared terminology is prepared for French, Spanish, Russian and Simplified Chinese, but full translated page content is not yet published. Add a locale's static routes only when each page has reviewed content, translated navigation and localised metadata.
