## ENGO discount code: DSLWHL_40

Use the ENGO promo code **DSLWHL_40** to get **40€ or $40 off all currently available ENGO smart-glasses models, depending on your region**.
{: .notice--info}

This is a special discount negotiated for the EUC community. Using the code also helps support WheelDash development at no extra cost to you.

WheelDash supports ENGO smart glasses on both Garmin and Amazfit, displaying riding information and alerts directly in your field of view.

I’m also continuing to work on the ENGO integration. ENGO 3 support is coming soon, including support for its new colour display in the Amazfit version.

If you found an older ENGO coupon, please note that it may no longer work; **DSLWHL_40** is the current WheelDash ENGO discount code.
